Agent 轨迹评分

上传或粘贴同一任务的 JSON。评分只看工具序列、随机 nonce 和最终状态，不信任模型自报字段。

建立可信 Agent 基线

先在官方或你完全信任的端点上，用相同 profile 采集轨迹，再导入这里。不要把不同档位的轨迹混合。

路由漂移

输入每次任务经过可信层推断出的模型标签；系统只在相同 profile_key 内统计。

Agent 行为归因

对同一 profile 的轨迹分别比较 Sol/Terra/Luna 基线；多模型同时匹配时返回“ambiguous”，不会强行指定型号。
